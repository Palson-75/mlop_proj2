# 🚀 End-to-End ML Pipeline with MLOps

This project demonstrates a complete end-to-end Machine Learning pipeline integrated with MLOps practices such as experiment tracking, model versioning, containerization, and cloud storage.

## 📌 Overview
The goal of this project is to build a scalable and reproducible ML system that handles the entire lifecycle:
- Data ingestion
- Data preprocessing
- Model training & evaluation
- Model tracking and versioning
- Deployment-ready pipeline

## 🛠️ Tech Stack
- Python
- Scikit-learn / PyTorch

- Docker (containerization)
- CI/CD pipelines
